# 🗺️ The Dark Atlas

Welcome! 👋

This repository contains the official website for The Dark Atlas, an interactive archive dedicated to mysteries, legends, lost civilizations, unexplained events, and strange stories from around the world.

The Dark Atlas brings together detailed case files, historical records, evidence, theories, locations, and stories that continue to resist simple explanations, all wrapped in an atmospheric cabin-inspired experience.

## 🌐 Live Website

Explore The Dark Atlas here:

https://vampriyad.github.io/The-Dark-Atlas/

## 🚀 About The Dark Atlas

The Dark Atlas is built for anyone fascinated by the unexplained, forgotten history, strange stories, and mysteries that continue to capture people's imagination.

Each mystery is presented as a detailed case file, bringing together its legend, history, evidence, theories, and what remains unexplained.

## ✨ Features
🗂️ Interactive Mystery Archive
📁 Detailed Case Files
